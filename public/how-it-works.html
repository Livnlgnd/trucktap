How it works

From tap to restock in three steps.

TruckTap keeps the field workflow simple and gives the shop a list it can act on. No account, no signal, and no spreadsheet required.

1

Set up your van

Name the van, add the technician, and choose a starting parts list. Use Electrical & Controls, Plumbing & Drain, Apartment/Multifamily, or start empty. You can add more vans from Manage Van Templates.

2

Tap what you used

Tap +1 for every part you use. Add an optional job or unit number. Every tap saves to the device immediately, so the clicker keeps working in dead zones. Hold a tile to subtract one if you mis-tap.

3

Send the restock list

Send one list for the van. The shop sees a live pick-list, checks off each line as it is pulled, and generates a consolidated supplier order with CSV export. Mark the van restocked when it is loaded.

What the tech sees

A clicker built for gloves.

  • Large part tiles with used counts
  • Optional job or unit number
  • Search and category filters
  • Tap +1, hold to undo
  • Works offline with no account

What the shop sees

A pick-list, not a text thread.

  • Pending vans and parts needed
  • Check off each line as it is pulled
  • Consolidated supplier order
  • One-click CSV export
  • Mark the van restocked

Optional

Add Team Sync when devices need to share.

Local mode runs entirely on one device. Team Sync keeps tech field devices, the shop tablet, and the desktop on the same board, with an offline queue that flushes when a connection returns.
