Install

Three steps.

  1. Download the installer. Use the Windows button above.
  2. Run the setup file. Windows SmartScreen may warn because the installer is unsigned. Choose More info, then Run anyway.
  3. Activate your license. Open TruckTap, choose License & Downloads, and paste your signed key.

Before you install

What you need.

  • Windows 10 or 11, 64-bit
  • A local license key for full use, or the 30-day trial
  • No account required for local mode
  • Team Sync only if you want multiple devices sharing a board

Checksums are published with every release on GitHub.
