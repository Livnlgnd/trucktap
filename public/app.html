Mobile & web app

Install TruckTap
on your phone.

Open the full-screen web app on a phone, tablet, or desktop browser. It works offline and keeps the same restock board and local data on the device in your hand. Prefer Windows? Install the desktop app below.

Open the web app Download for Windows See pricing

On Android or desktop, the web app opens full-screen. On iPhone and iPad, add it to your Home Screen for the same experience.

⌂

iPhone & iPad

  1. Open the web app in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
▣

Android

  1. Open the web app in Chrome.
  2. Open the ⋮ menu.
  3. Tap Install app or Add to Home screen.
⌘

Desktop browsers

  1. Open the web app in Chrome or Edge.
  2. Click the install icon in the address bar.
  3. Confirm the install.

Already have a license?

Activate in the app.

Open the web app or the Windows desktop app, choose License & Downloads, and paste your signed key. The app verifies it offline and unlocks your plan.

Retrieve my license See pricing
  1. Open TruckTap. Use the web app on this device or the Windows desktop app.
  2. Go to License & Downloads. Paste your key and activate.
  3. Start tapping. Your plan limits unlock immediately.
