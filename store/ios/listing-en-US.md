**Promotional text:**

**Description:**
TruckTap is the glove-friendly restock board for service vans.

Technicians tap the parts they used. The shop gets a clean pick-list and a
consolidated supplier order. It works offline, and optional Team Sync keeps the
field, the shop tablet, and the office on the same board when a connection is
available.

TAP USED PARTS
- Large, glove-friendly part tiles
- +1 and -1 taps with hold-to-undo
- Categories and instant search
- Optional job or unit tag

SHOP PICK-LIST
- Live pending lines across every van
- Pick and restock tracking
- Consolidated supplier order
- CSV export for purchasing

BUILT FOR THE FIELD
- Local-first and offline-ready
- No TruckTap account required for local mode
- Team Sync is optional
- Uses the same TAP license as the Windows desktop app

SET UP YOUR WAY
- Electrical, plumbing, and multifamily starter templates
- Editable parts, categories, and par levels
- Multiple vans per shop

Already using TruckTap on Windows? Install the companion, paste your existing
TAP license key, and optionally sign in to the same Team Sync workspace.

TruckTap is licensed, not sold. A 30-day trial is included.
