TRUCKTAP - VAN RESTOCK CLICKER
==============================

Thank you for purchasing TruckTap.

WHAT IS INCLUDED
----------------
TruckTap-Setup-<version>.exe  Windows installer
TruckTap-User-Guide.pdf       Step-by-step user guide
TruckTap-README.txt           This file
TRUCKTAP-TERMS.txt            Terms of Service

The same documents are installed next to TruckTap.exe and are linked from
TruckTap Docs in the Start menu.

SYSTEM REQUIREMENTS
-------------------
- Windows 10 or 11, 64-bit
- A modern browser (for the web app)
- Internet access only for optional Team Sync

INSTALL
-------
1. Run the setup file.
2. Accept the Terms of Service.
3. Open TruckTap from the Start menu or desktop shortcut.

Windows SmartScreen may warn because the installer is not code-signed.
Choose "More info", then "Run anyway".

ACTIVATE
--------
Open the License tab and paste the TAP- license key from your purchase email.

Your key is verified offline on this device. A 14-day trial is available before
activation. Lost the email? Use https://trucktap.net/license.html with the
Stripe checkout session ID from your receipt.

FIRST RUN
---------
Name your van and choose an Electrical, Plumbing, or Multifamily starter list.
You can skip the template and add parts manually. Everything is editable later.

DAILY WORKFLOW
--------------
Tech view:
  Tap +1 for a used part, -1 to correct a tap, or hold to undo.
  Submit the restock list when the job is done.

Shop view:
  Pick each line, export the supplier order as CSV, and mark the van restocked.

Manage view:
  Add vans, edit parts, set par levels, load templates, or reset local data.

TEAM SYNC (OPTIONAL)
--------------------
Team Sync shares one workspace across the field, the shop tablet, and the
office. Open Team, create or join a workspace, and share the join code.
Offline changes queue automatically and sync when the device reconnects.

Signing out stops sync but keeps a local copy on the device.

DATA AND BACKUPS
----------------
The local board is stored in the app's data folder (Help > Open Data Folder in
the desktop app) or in browser site data for the web app. There is no account
and no cloud copy unless you enable Team Sync.

- Keep Team Sync on for a shared copy across devices.
- Export the supplier order CSV before clearing a device.
- Close TruckTap before copying its data folder.
- Clearing browser site data removes the local web board.

UPDATES
-------
Download the newest installer from https://trucktap.net/app.html.
Installing over an existing copy keeps your local data. Your license continues
to work after the included update window ends; renewals are optional.
